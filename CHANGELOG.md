# Changelog

## 1.0.24
- Релизная полировка после серии правок.
- Добавлен конфиг через Mod Menu:
  - общий переключатель мода;
  - отдельное включение/выключение боевого режима для каждого предмета;
  - отдельная длительность боевого режима (в секундах) для каждого предмета.
- Поддержка настроек для предметов:
  - арбалет, снежок, яйцо, заряд ветра;
  - лук, трезубец;
  - меч, булава, топор.
- Стабилизированы переходы камеры при посадке/слезании и боевых режимах.
- Переименован артефакт сборки в `PWrideperspective-1.0.24.jar`.

## 1.0.0
- Базовый выпуск мода PWrideperspective для Fabric 1.21.4.
