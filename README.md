# PWrideperspective

Клиентский Fabric-мод для Minecraft 1.16.5 с кинематографичной камерой при езде на мобах, независимым управлением и боевыми режимами камеры.

## Возможности
- Плавные переходы камеры при посадке и сходе с транспорта.
- Независимое управление транспортом от направления камеры.
- Боевой режим от первого лица для арбалета, снежка, яйца, лука, трезубца, меча и топора.
- Настройки через Mod Menu, включая включение и выключение мода.

## Конфигурация
Файл настроек: `config/pwrideperspective.json`.

## Сборка
```powershell
./gradlew.bat remapJar
```

Готовый JAR находится в `build/libs`.
