# PWrideperspective

Клиентский Fabric-мод (Minecraft 1.21.11) с кинематографичной камерой при езде на мобах, независимым управлением и боевыми режимами камеры.

## Что умеет
- Плавные переходы камеры при посадке/слезании.
- Независимое управление маунтом от положения камеры.
- Боевой 1st-person режим для:
  - арбалета, снежка, яйца, заряда ветра;
  - лука и трезубца;
  - меча, булавы и топора.
- Настройки через Mod Menu (включая включение/выключение мода).

## Конфиг через Mod Menu
В меню мода можно:
- включить/выключить мод целиком;
- включить/выключить боевой режим для каждого предмета отдельно;
- задать длительность боевого режима в секундах для каждого предмета отдельно.

Файл конфига: `config/pwrideperspective.json`

## Сборка
```powershell
./gradlew.bat build
```

Готовый jar находится в `build/libs`.
